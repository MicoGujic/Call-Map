# Security

## Reporting a problem

Please report security problems privately, through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Don't open a public issue for them.

Say what you found, which version of Call Map and VS Code you used, and how to reproduce it. You'll get an answer in the advisory, and the fix will be credited to you in the changelog unless you'd rather not.

## Supported versions

Fixes go into the latest release. Update to it from the Marketplace or the Releases page.

The README's [Privacy and security](README.md#privacy-and-security) section lists what Call Map reads, keeps and writes, and how it relates to network access.
